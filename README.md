# Архив Wildberries в Telegram

Бот получает данные двух кабинетов WB, хранит исходные ответы API и отправляет ZIP с Excel в личные чаты разрешённых пользователей. Автоматическая загрузка — каждый день в 10:00 по Москве. Код не изменяет цены, остатки, заказы или другие данные в WB.

## Что подключено

- Ежедневные отчёты реализации за прошедший день: реестр и детализация.
- Текущий баланс и доступная сумма к выводу.
- Остатки на складах WB и складах продавца FBS.
- Карточки товаров, включая корзину; цены и скидки.
- Заказы, продажи и возвраты из оперативных отчётов.
- Документы продавца во всех доступных форматах и реестр в Excel.
- Издержки на приём платежей, платное хранение, операции при приёмке.

Кнопка «Скачать за вчера» получает отчёты и документы только за предыдущий календарный день по Москве. Например, запуск 9 октября загружает данные за 8 октября. Баланс, цены, карточки и текущие остатки — снимки на момент обращения к API. История остатков CSV, рекламная статистика, сборочные задания и расширенная аналитика пока не подключены. Еженедельные отчёты и полная история отключены.

Данные заказов и продаж предварительные и не заменяют финансовую детализацию. WB может публиковать данные с задержкой. Эта версия не перепроверяет более ранние дни и не догружает пропущенную историю. Старые настройки DAILY_LOOKBACK_DAYS, FINANCE_HISTORY_START и OTHER_HISTORY_START игнорируются и не увеличивают период загрузки.

## Настройка

1. Создайте отдельного Telegram-бота через @BotFather.
2. Скопируйте `.env.example` в `.env` и заполните TELEGRAM_BOT_TOKEN.
3. Впишите токены двух кабинетов WB и названия кабинетов. Нужны категории Финансы, Аналитика, Статистика, Контент, Маркетплейс, Документы, Цены и скидки. Выберите права «Только чтение». POST здесь используется и для чтения/генерации отчётов.
4. Укажите числовые ID пользователей в ALLOWED_USER_IDS. RECIPIENT_IDS — получатели ежедневной рассылки, также входящие в белый список.
5. Каждый получатель должен открыть бота и нажать «Начать»: бот не может первым начать личный диалог.

Токены задаются через секреты хостинга или локальную `.env`. Не добавляйте `.env`, папку `data` и архивы в репозиторий. Персональный токен WB предназначен для собственной интеграции на вашей или арендованной инфраструктуре. Если используется сервис из каталога WB, требуется соответствующий Сервисный токен и, когда применимо, CLIENT_SECRET. Базовый токен не даёт доступ ко всем нужным финансовым методам.

## Запуск на хостинге

В репозитории есть Dockerfile и compose.yaml. Запустите:

```sh
docker compose up -d --build
```

Хостинг должен поддерживать постоянно работающий процесс, исходящий HTTPS и постоянный диск. В compose используется постоянный том `/data`; при размещении другим способом задайте DATA_DIR на постоянный диск. Отдельный домен, входящий порт и webhook не нужны: используется long polling. Запускайте одну реплику. Другой экземпляр с тем же DATA_DIR будет отклонён; на разных дисках всё равно нельзя запускать две реплики одного Telegram-бота.

Для хостинга, который запрашивает файл запуска, укажите **main.py**. Команда запуска из корня проекта: `python main.py` (также подходит `python -m wb_backup`). Команда установки зависимостей: `pip install -r requirements.txt`. В корне проекта должны находиться main.py, requirements.txt и папка wb_backup со всеми файлами. После распаковки архива корнем является вложенная папка wb-backup-bot.

Не указывайте tests/test_bot.py в качестве файла запуска: он выполняет проверки и завершается, а не запускает бота. Ошибка `ModuleNotFoundError: No module named 'wb_backup'` в этом файле возникает при прямом запуске тестов без корня проекта в пути импорта. Прямой запуск тестов теперь поддерживается, но для работающего бота всё равно нужен main.py.

Если токен уже используется ботом с webhook, программа остановится с понятным сообщением. Используйте отдельный токен либо предварительно отключите существующий webhook.

Запуск без Docker, Python 3.12:

```sh
python -m venv .venv
# Linux:
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m wb_backup
# Windows: используйте .venv/Scripts/python.exe
```

## Команды

| Команда/кнопка | Действие |
| --- | --- |
| `/start` | Приветствие «Что подключено» и кнопки |
| `/help`, «Помощь» | Описание команд и кнопок |
| `/connected`, «Что подключено» | Список подключённых источников |
| `/daily`, «Скачать за вчера» | Отчёты обоих кабинетов за вчера и текущие снимки |
| `/status`, «Статус» | Текущее задание, этап, время и ошибки |
| `/retry`, «Продолжить загрузку» | Продолжить последнюю неполную загрузку и неотправленные файлы |

При запуске процесса бот отправляет получателям ежедневной рассылки сообщение «Бот запущен» со списком источников и кнопками. Получатель должен заранее нажать «Начать» в Telegram. При `/start` пользователь видит тот же список. Команды также регистрируются в меню Telegram. Список означает подключённые в программе источники; фактический доступ WB проверяется при выгрузке.

Загрузка идёт в фоне, между запросами соблюдаются паузы WB. Источники со снимками идут перед отчётами. При повторном нажатии во время работы новая задача не запускается. Если хостинг не работал в 10:00, при запуске после 10:00 выполняется загрузка только за вчера. Старые команды `/all` и «Скачать всё» больше не запускают задания. «Скачать свежие данные» для совместимости запускает только вчерашний день.

При обновлении остановите старый процесс и перезапустите бот с новым кодом. Старые многодневные задания в очереди автоматически отменяются; скачанные файлы остаются на диске. Они не возобновляются через `/retry`. Настройки Telegram и токены менять не требуется. Новое меню заменит старые кнопки при запуске или `/start`.

## Архив и восстановление

Внутри ZIP отдельные папки двух кабинетов, Excel, исходные JSON и оригиналы документов. `РЕЕСТР.xlsx` и `РЕЕСТР.json` указывают результаты каждого источника; запросы в папке raw содержат период, время получения и точный ответ WB. Есть контрольные суммы файлов.

Ошибка одного источника не останавливает остальные источники и второй кабинет. Неполная загрузка явно обозначена. `/retry` использует сохранённые ответы и продолжает незавершённые этапы одного дня; дата фиксируется по времени создания задания. После перезапуска однодневные задания возвращаются в очередь. Архивы версионируются по номеру задания, поэтому новая загрузка не уничтожает старые отчёты. Для повтора заново с актуальными данными запустите `/daily` после окончания текущей задачи.

Части ZIP имеют размер до 45 МиБ и распаковываются в одну папку. В большинстве случаев внутри обычные Excel-файлы. Если отдельный оригинальный документ слишком большой, он делится на `*.chunk00001` и далее. После распаковки всех частей восстановите его:

```sh
python join_chunks.py <папка_распаковки>
```

Длинные ID и штрихкоды записываются в Excel как текст. Денежные строки известных полей с точностью до 15 значащих цифр преобразуются в числа; значения большей точности остаются текстом. Точная первичная информация всегда сохраняется в JSON. Длинные тексты и вложенные массивы в Excel ограничены возможностями ячейки, полный вариант находится в JSON. По одной странице API создаётся отдельная книга; большие страницы делятся на листы по 50 000 строк.

Папка DATA_DIR содержит конфиденциальные данные продавцов. Ограничьте доступ к постоянному диску и Telegram-аккаунтам получателей. Архивы не удаляются автоматически: следите за свободным местом и настройте независимую резервную копию DATA_DIR на хостинге. Telegram и один диск не гарантируют восстановление при утрате обоих.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют белый список, расписание, границы вчерашнего дня по Москве, отмену старых заданий, пагинацию, ошибки/повторы API, Excel и восстановление больших файлов. Они не обращаются к реальным кабинетам и Telegram. После настройки сверить одну ежедневную выгрузку с кабинетами WB и проверить получение файлов всеми получателями.

Официальные источники: [Финансы и документы](https://dev.wildberries.ru/docs/openapi/financial-reports-and-accounting), [аналитика](https://dev.wildberries.ru/en/openapi/analytics), [оперативные отчёты](https://dev.wildberries.ru/en/openapi/reports), [товары и FBS](https://dev.wildberries.ru/openapi//work-with-products), [токены WB](https://dev.wildberries.ru/news/150), [Telegram Bot API](https://core.telegram.org/bots/api).
